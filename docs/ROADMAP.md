# Roadmap

## Pre-alpha 0.2

- Native Godot desktop version.
- Basic voxel world.
- Casse and pose blocks.
- Editable textures and sounds.

## Pre-alpha 0.3

- Larger procedural world with hills, mountains, caves and deeper terrain.
- Survival and Creative mode selection.
- Inventory counts.
- Crafting screen.
- Health, fall damage, Game Over and respawn.
- Dropped item recovery after death.

## Next

- Main menu world selection.
- Mod manifests.
- More blocks, tools and survival systems.
- Cleaner modding hooks for blocks, recipes and world generation.

## Later

- Optional community extensions only after the local game is solid.
- No official default server baked into the project.
