# Roadmap

## Pre-alpha 0.2

- Native Godot desktop version.
- Basic voxel world.
- Casse and pose blocks.
- Editable textures and sounds.

## Pre-alpha 0.3

- Larger procedural world with hills, mountains, caves and deeper terrain.
- Survival and Creative mode selection.
- Inventory counts.
- Crafting screen.
- Health, fall damage, Game Over and respawn.
- Dropped item recovery after death.

## Pre-alpha 0.4

- Worldgen V2.
- Larger world bounds.
- Higher mountains and deeper underground space.
- Simple biomes for meadow, forest, coast, dry, rocky and mountain zones.
- Safer spawn transition between the start area and natural terrain.
- Deeper caves with tunnel and pocket noise.
- Editable world generation settings in `assets/worldgen.json`.
- Loading screen while creating a world.
- Spawn chunks prepared before player control is enabled.
- Worldgen V2 split into its own module.
- Essential terrain blocks: deep stone, gravel, rocky dirt, wet sand, copper ore and rare ore.
- C# migration path documented for a future Godot .NET setup.

## Next

- Main menu world selection.
- Useful survival blocks: primitive furnace, chest, torches and stronger workbench progression.
- Tools and survival systems.
- Improved 32x32 block textures.
- Mod manifests.
- Cleaner modding hooks for blocks, recipes and world generation.

## Later

- Optional community extensions only after the local game is solid.
- No official default server baked into the project.
