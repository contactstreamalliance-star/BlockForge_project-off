# BlockForge Alpha - Sources des assets temporaires

Cette alpha utilise quelques assets gratuits comme base temporaire. Ils ne sont pas le style final du jeu, mais ils permettent de tester Godot, les collisions, la camera, l'ambiance et les interactions pendant que le vrai coeur voxel est construit.

## Godot Asset Store - Chibi Characters

- Source : https://store.godotengine.org/asset/styloo/chibi/
- Auteur : styloo
- Licence affichee sur le store : CC0 1.0 Universal
- Usage dans BlockForge Alpha :
  - profils temporaires de joueur ;
  - tests de camera et d'animation ;
  - placeholders a remplacer par des skins plus simples ou plus cubiques.

## Regle de production

Ces assets doivent etre traites comme placeholders propres, pas comme direction artistique finale.

La direction finale de BlockForge Alpha reste :

- monde de blocs ;
- textures modifiables ;
- sons 8-bit ou retro ;
- interface simple ;
- fichiers ouverts ;
- modding communautaire ;
- jeu local avant tout.

Quand le coeur voxel sera stable, il faudra remplacer progressivement ces assets par :

- blocs originaux ;
- outils et objets simples ;
- creatures locales si besoin ;
- skins ou personnages plus coherents avec un Minecraft-like ;
- props de craft compatibles avec le style BlockForge.
